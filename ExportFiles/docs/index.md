# ExportFiles
Библиотека предназначена для формирования подлинников на основе файлов grb сделанных в T-FLEX CAD

Основными компонентами библиотеки являются
* Экспорт номеналатуры - [NomenclatureExport](./NomenclatureExport.md)
* Экспорт номенклатуры из ИИ - [ModificationNoticeExportNomenclature](./ModificationNoticeExportNomenclature.md)
* Кофигурации экспорта - [Работа с конфигурациями](./Configs.md)
* Обработчик файлов - 
* Экспортер файла
* Управление значениями переменных CAD
